# SignedChange 2.0 design system

This folder is the Milestone 3 foundation. It does not replace `site/` and it is not wired into the Worker. Milestone 4 implements these rules in the live pages.

Public copy that is new uses `https://signedchange.com`. Existing PayPal return and notify URLs stay as they are in `site/app.js` until a separately approved payment change. This milestone does not edit them.
