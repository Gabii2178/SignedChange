How it works

  1. Write the change

    Title, what changed, both people, and any money or schedule impact. A template only fills the form on this device.

  2. Review

    Read the summary before anyone signs. The change-order number is assigned when the document is created.

  3. Sign and share

    Sign on this device, or send a link. The link is not stored on the server for you to recover from another device unless this browser kept a copy.

  4. Keep the PDF

    Download the same file from the account, or from the view link after signing.

Create a change record

Put a change in writing, get both sides to sign, and keep a record.
