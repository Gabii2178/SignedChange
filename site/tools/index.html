Why we built these tools

SignedChange helps people put changed agreements in writing and get them signed in a minute. Along the way we kept hearing the same questions: how much should I charge, how do I bill the extra work, how much interest can I add to a late invoice, and what does a change order look like? These free tools answer those questions quickly, on any phone.

Every tool runs fully in your browser. Nothing you type is uploaded, so you can use real client names and numbers safely.
